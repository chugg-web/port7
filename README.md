# Сериализация, десериализация и валидация JSON

Домашнее задание. Язык: JavaScript (Node.js, без зависимостей).

## Запуск
```bash
node todo.js     # базовый уровень
npm start        # оба уровня (index.js)
```

## Файлы
- `todo.js` — **базовый уровень**: массив задач → JSON-строка → файл `tasks.json` → чтение обратно и сравнение.
- `validator.js` — **продвинутый уровень**: `validateJson(jsonString, schema)` проверяет синтаксис JSON, наличие обязательных полей (`id`, `email`, `roles`) и их типы; возвращает `{ valid, errors, data }`.
- `index.js` — демонстрация с корректными и некорректными данными.
